# فواتير النسر الذهبي (Golden Eagle Invoice App)

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose + Room + PdfDocument) مخصص لـ **شركة النسر الذهبي** لأعمال الكهرباء والشبكات وأنظمة المراقبة والحريق، لإنشاء وإدارة الفواتير وعروض الأسعار وتصديرها كملفات PDF A4 جاهزة للطباعة والمشاركة.

## الميزات الرئيسية
- **توليد PDF A4 مطابق لقالب الشركة (`26-0101`):** الترويسة الخطية، الشعار (الأحمر والذهبي أو الذهبي الكامل من الإعدادات)، العلامة المائية الشفافة، جدول 17 سطراً مع دعم التوسّع التلقائي لصفحات إضافية، المجاميع، الملاحظات، والختم الرسمي (`company_stamp.png`).
- **الختم والتوقيع اليدوي:** إظهار/إخفاء الختم لكل فاتورة + لوحة رسم توقيع يدوي بالإصبع.
- **تعدد العملات والتفقيط العربي التلقائي:** دعم الدينار الليبي (`د.ل`)، الدولار الأمريكي (`$`)، واليورو (`€`) مع تحويل المبلغ النهائي تلقائياً إلى كلمات عربية والتحكم في عدد الخانات العشرية.
- **سجل الفواتير والنسخ والتحويل:** حفظ محلي كامل (يعمل 100% بدون إنترنت)، بحث وتصفية، نسخ الفواتير، وتحويل عروض الأسعار إلى فواتير نهائية.
- **كتالوج الأصناف ودليل الزبائن:** حفظ الأجهزة والخدمات المتكررة وأسعارها وبيانات الزبائن للإدخال السريع.
- **معاينة، مشاركة واتساب، حفظ، وطباعة:** معاينة فورية داخل التطبيق مع مشاركة مباشرة عبر واتساب وحفظ في مجلد التنزيلات وطباعة مباشرة.
- **نسخ احتياطي واستعادة (JSON):** تصدير واستيراد كامل البيانات كملف واحد عبر Android SAF.

## متطلبات البناء
- Android Studio (Ladybug أو أحدث)
- JDK 17
- Android SDK 34 (`minSdk = 24`, `targetSdk = 34`)

```bash
./gradlew :app:assembleDebug
```
